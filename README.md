# Groceries App

Um aplicativo simples de compras de supermercado desenvolvido com Flutter. Este projeto demonstra conceitos fundamentais do Flutter, incluindo gerenciamento de estado com o pacote `provider`, arquitetura baseada em componentes e animações de UI.

## ✨ Features

-   Navegue por uma lista de produtos.
-   Adicione e remova itens do carrinho de compras.
-   Visualize o carrinho com o cálculo do preço total.
-   Feedback visual com animações ao adicionar um item.


## 🚀 Começando

Siga estas instruções para obter uma cópia do projeto e executá-lo em sua máquina local para desenvolvimento e testes.

### Pré-requisitos

É necessário ter o **Flutter SDK** instalado em sua máquina. Se você ainda não o tem, siga o guia de instalação oficial:

-   [Instalação do Flutter](https://docs.flutter.dev/get-started/install)

### Instalação

1.  **Clone o repositório**
    ```bash
    git clone <URL_DO_SEU_REPOSITORIO>
    cd hello
    ```

2.  **Instale as dependências**
    Execute o seguinte comando no diretório raiz do projeto para baixar todos os pacotes necessários:
    ```bash
    flutter pub get
    ```

## 🏃‍♀️ Executando a Aplicação

Após a conclusão da configuração, você pode executar o aplicativo em um dispositivo conectado ou em um simulador.

1.  Certifique-se de que um dispositivo ou simulador esteja em execução.

2.  Execute o comando:
    ```bash
    flutter run
    ```

## 🛠️ Pacotes Utilizados

-   [provider](https://pub.dev/packages/provider): Para gerenciamento de estado.
-   [google_fonts](https://pub.dev/packages/google_fonts): Para fontes personalizadas.
-   [intl](https://pub.dev/packages/intl): Para formatação de moeda.
-   [flutter_launcher_icons](https://pub.dev/packages/flutter_launcher_icons): Para gerar os ícones do aplicativo.
